# Bind one fulfillment charge and prove allocation closure before compensation

Status: Accepted. Date: 2026-10-11. Decision: D-045.

Payment binds one eligible verified charge to an Order, and Inventory owns the guarded allocation decision. Selected-charge compensation needs durable closure proof; confirmed allocations finish the same Booking Order. Evidence queries add latency but prevent stale refunds; see D-045 and Review 045 for the full contract.
