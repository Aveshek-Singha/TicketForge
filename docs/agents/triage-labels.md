# Triage labels

## Default vocabulary
| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Evaluate an incoming issue. |
| needs-info | needs-info | More reporter information is required. |
| ready-for-agent | ready-for-agent | Approved agent work; native blockers still gate starting. |
| ready-for-human | ready-for-human | Requires human implementation. |
| wontfix | wontfix | Will not be actioned. |
Tickets generated by to-tickets are already ready-for-agent. Do not put them through triage again.
